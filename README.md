# Power Shell Command Collection 🛠️

รวมคำสั่ง PowerShell และ Batch Script ที่มีประโยชน์สำหรับชีวิตประจำวันและการตั้งค่าระบบต่าง ๆ บน Windows ให้ง่ายและสะดวกขึ้น

---

## 📂 สารบัญคำสั่งในคลังนี้ (Table of Contents)

คุณสามารถคลิกเข้าไปดูรายละเอียดและวิธีใช้งานคำสั่งแต่ละส่วนได้จากลิงก์ด้านล่างนี้ครับ:

### 1. [🔑 Generate Password (สุ่มรหัสผ่าน)](./generate_password/generate_password.md)
* **รายละเอียด:** คำสั่ง PowerShell สำหรับสุ่มรหัสผ่านที่มีความปลอดภัยสูงและเดายาก สามารถกำหนดความยาวหลักได้ตามต้องการ

### 2. [🌐 Network Reset (รีเซ็ตเครือข่าย)](./network_reset/network_reset.md)
* **รายละเอียด:** สคริปต์ Batch File (`.bat`) สำหรับการล้างค่า DNS Cache, รีเซ็ต IP Address และรีเซ็ต Network Stack เพื่อแก้ไขปัญหาการเชื่อมต่ออินเทอร์เน็ตขัดข้อง

### 3. [🔑 Get Windows Product Key (ดึงคีย์ลิขสิทธิ์ Windows)](./get_windows_key/get_windows_key.md)
* **รายละเอียด:** คำสั่งดึงรหัส Product Key (คีย์ลิขสิทธิ์แท้ 25 หลัก) ที่ผูกอยู่กับเมนบอร์ดออกมาแสดง สำหรับสเปกเครื่อง OEM

### 4. [🧹 Delete Empty Folders (ลบโฟลเดอร์ว่าง)](./delete_empty_folders/delete_empty_folders.md)
* **รายละเอียด:** คำสั่งค้นหาและลบโฟลเดอร์ย่อยที่ว่างเปล่า (Empty Folders) ภายในโฟลเดอร์เป้าหมายทั้งหมดในครั้งเดียว

### 5. [⚡ CUDA on Windows 11](./cuda_window_11/README.md)
* **รายละเอียด:** คู่มือขั้นตอนการติดตั้งและตั้งค่า CUDA Toolkit บนระบบปฏิบัติการ Windows 11 สำหรับงาน AI/Machine Learning หรือการพัฒนาโปรแกรม

---

## 🚀 วิธีการใช้งานทั่วไป (How to Use)

1. เลือกโฟลเดอร์ของคำสั่งที่ต้องการใช้งาน
2. คัดลอกคำสั่งในบล็อกโค้ดตัวอย่างไปวางใน **PowerShell** หรือสร้างไฟล์ `.bat` ตามคำแนะนำในแต่ละโฟลเดอร์
3. กด **Enter** เพื่อสั่งให้ทำงาน
