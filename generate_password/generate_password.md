# Generate Secure Password (สุ่มรหัสผ่านที่ปลอดภัย)

คำสั่ง PowerShell สำหรับสุ่มรหัสผ่าน (Password) ที่มีความปลอดภัยสูง เดายาก ประกอบด้วยตัวอักษรภาษาอังกฤษพิมพ์ใหญ่ พิมพ์เล็ก และตัวเลข

## คำสั่ง PowerShell
คัดลอกคำสั่งด้านล่างนี้ไปวางใน PowerShell แล้วกด **Enter** ได้เลยครับ:

```powershell
-join ((48..57) + (65..90) + (97..122) | Get-Random -Count 12 | ForEach-Object {[char]$_})
```

---

## วิธีใช้งานและปรับแต่ง

1. **เปิดโปรแกรม PowerShell** บน Windows ของคุณ
2. **คัดลอกคำสั่งด้านบน** ไปวาง (คลิกขวาเพื่อวางใน PowerShell) แล้วกด **Enter**
3. ระบบจะสุ่มรหัสผ่านขนาด 12 ตัวอักษรขึ้นมาทันที

### การปรับแต่งความยาวรหัสผ่าน
หากต้องการเพิ่มหรือลดความยาวของรหัสผ่าน สามารถแก้ไขตัวเลขหลัง `-Count` ได้ตามต้องการ:
* สำหรับรหัสผ่าน **16 หลัก**:
  ```powershell
  -join ((48..57) + (65..90) + (97..122) | Get-Random -Count 16 | ForEach-Object {[char]$_})
  ```
